# Roasted Beans Coffee Shop 

A simple website for a small-batch roasted coffee shop, built with HTML and CSS.

## Overview
This project showcases the coffee shop's story, values, and what makes it stand 
out — built as a clean, responsive single-page site.

## What's Been Added
- **Styling** — Added `style.css` to give the site a consistent, polished look 
  (colors, spacing, typography)
- **Hero Section** — Added a heading and a more polished intro paragraph 
  introducing the brand
- **Our Story Section** — Added a paragraph telling the story behind the shop
- **Why Customers Come Back Section** — Added a paragraph explaining what keeps 
  people returning
- **Cards Section** — Added feature cards highlighting key selling points 
  (ethically sourced, small-batch roasted, crafted with care)

## What's Been Fixed / Improved
- Rewrote the hero paragraph to sound more polished and on-brand
- Rewrote the "why people come back" section for a clearer, warmer tone
- Improved heading structure for better readability
- Applied consistent styling across sections using external CSS instead of inline styles
